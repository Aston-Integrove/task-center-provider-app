# S-01 - Path and parameters Task Center uses (T006-03)

**Time-box:** 0.5 day · **Needs:** deployed environment (`azd up`), BTP subaccount access, T006-01 answers (Q-01..Q-03).
**Status:** not run.

## Steps

1. `azd env get-values | grep APP_FQDN` -> `https://<fqdn>`.
2. In the BTP cockpit create destination `INTEGROVE_TP` exactly as in [btp-setup-guide.md](../btp-setup-guide.md) section 2
   (`OAuth2ClientCredentials`, token URL `https://<fqdn>/oauth/token`, client `tc-tech`, `tc.enabled=true`, `tc.provider_type=Custom`).
   First try URL `https://<fqdn>/task-provider/v2`; if nothing arrives, retry with `https://<fqdn>/api/task-provider/v2`
   (both prefixes are served, so the request log tells you which one Task Center appended to).
3. In Task Center admin, open the connector and trigger/await the definition pull and the INITIAL task pull.
4. Admin console -> *Requests* (prefix `/oauth`, then `/task-provider`, then `/api/task-provider`). Expand each row.
