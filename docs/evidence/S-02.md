# S-02 - Principal propagation: assertion, issuer, claims (T006-04)

**Time-box:** 1 day · **Needs:** S-01 done, users from T006-02 provisioned (S-03 can run first), `INTEGROVE_TP_PP` destination.
**Status:** not run.

## Question

Does the `_PP` destination reach `/oauth/token` with a user assertion; which issuer and claim names does it carry; and is
`OAuth2JWTBearer` enough, or must we switch to the SAML bearer grant (risk R-01)?

## Steps

1. Turn on claim logging: set `Diagnostics__LogAssertionClaims=true` on the Container App (names and the resolved user id are
   logged, never the token).
2. **Without Task Center:** call the Destination service "find destination" API for `INTEGROVE_TP_PP` with
   `X-user-token: <a user JWT from the BTP/IAS login>` (a small test app or `curl`). The response contains `authTokens[0].value`,
   the access token minted by our `/oauth/token`. This checks the whole chain in isolation.
3. Paste the **user JWT** into admin console -> *Diagnostics* -> *Decode assertion*. It shows header, claims, whether the issuer
   is trusted, and how the Global User ID would resolve (`userResolution.via`).
4. **With Task Center:** open a task as U1 (description, then approve). Check *Requests* for `POST /oauth/token`
   (`grant_type`) followed by `GET .../description` and `POST .../response`.

## Decision

- [ ] **JWT bearer works** -> add the issuer to `OAuth__TrustedAssertionIssuers__n`, set `OAuth__UserIdClaims` to the observed order.
- [ ] **JWT bearer is not accepted** -> enable the SAML fallback (T002-14): `Saml__Enabled=true`, store the subaccount trust
      certificate as Key Vault secret `btp-saml-trust-cert`, allow the grant on client `tc-pp`
      (`OAuth__Clients__1__AllowedGrants__1=urn:ietf:params:oauth:grant-type:saml2-bearer`), switch the destination to
      `OAuth2SAMLBearerAssertion`; update ADR-004 and open the SAP influence request (Q-04).

## Exit criteria

- [ ] Trusted issuer + `UserIdClaims` configured, or the SAML decision taken and ADR-004 updated.
- [ ] E2E-05..E2E-10 can be attempted.
